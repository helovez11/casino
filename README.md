# Social Casino (MVP, без сборки)

Это минимальный прототип **social casino** (слоты на виртуальные монеты) — **без вывода денег**.

## Как запустить

### Вариант А (самый надёжный): через локальный сервер

Если кнопки/скрипты не работают при открытии `index.html` напрямую, запусти сайт как обычную страницу через HTTP:

```bash
python -m http.server 5173
```

Потом открой в браузере `http://localhost:5173`.

### Вариант Б: просто открыть файл

Можно открыть `index.html` напрямую, но некоторые браузерные ограничения на `file://` иногда ломают JS.

Прогресс хранится в `localStorage` (внутри браузера).

- Магазин монет (пока **демо**, просто добавляет монеты без оплаты)
- Локальный топ (в браузере)

## Идеи монетизации (легально для social casino)

- Донат: монеты / VIP-статус / косметика / отключение рекламы
- Реклама: rewarded video (дать монеты за просмотр), баннеры
- Подписка: ежедневный VIP-бонус, быстрый автоспин и т.п.

## Если хочешь “нормальный” проект с деплоем

Сейчас сборки нет (так быстрее старт). Если установишь Node.js, можно перевести на Vite/Next, добавить бэкенд
(аккаунты, турнирные таблицы, анти-абуз, админку, платежи).

Если у тебя в терминале пишет “не найден node.exe” — установи Node.js LTS и перезапусти терминал.
